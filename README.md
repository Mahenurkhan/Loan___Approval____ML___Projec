# Loan Approval Prediction

A Machine Learning project for predicting loan approval using Logistic Regression and Naive Bayes algorithms.

## Project Overview
This project uses Machine Learning to predict whether a loan application will be approved based on applicant
information .

## Algorithms Used
- Logistic Regression
- Naive Bayes

## Technologies Used
- Python
- Pandas
- Scikit - learn
- Jupyter Notebook

## Dataset
The dataset is not included in this repository.
